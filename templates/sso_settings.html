Einrichtung Schritt für Schritt

1. Vorhandene Gruppen finden

Öffne Microsoft Entra → Entra ID → Gruppen → Alle Gruppen. Suche nach euren Stufen oder Teams. Öffne eine Gruppe, prüfe ihre Mitglieder und kopiere die Objekt-ID. Der Gruppenname allein reicht nicht. Fehlt der Bereich, braucht dein Microsoft-Konto die passende Leseberechtigung durch eure Administration.

2. Eigene SSO-App registrieren

App-Registrierungen → Neue Registrierung. Nur Konten dieses Organisationsverzeichnisses wählen. Plattform Web; diese Umleitungsadresse exakt eintragen:

{{ callback_url }}

Tenant-ID und Client-ID hier eintragen. Unter Zertifikate und Geheimnisse einen geheimen Clientschlüssel erstellen und dessen Wert samt Ablaufdatum hier speichern. Die App für den Mailversand bleibt getrennt.

3. Gruppeninformationen aktivieren

In der App unter Tokenkonfiguration einen Gruppenanspruch für Alle Gruppen hinzufügen, Gruppen als Objekt-IDs im ID-Token ausgeben. Dadurch können auch eure Microsoft-365-/Teams-Gruppen genutzt werden. Für Anmeldung genügen OpenID-Profilinformationen; MAP benötigt keine Mail.Send- oder Verzeichnis-Leserechte für diesen Ablauf.

Fehlen Gruppen oder überschreitet Microsoft die Token-Gruppengrenze, bleibt die manuelle Freigabe möglich. MAP ruft keine vom Token gelieferten Gruppen-URLs ab.

4. Zuordnen und freigeben

Gruppen-IDs euren Stufen zuordnen, speichern und testen. Unbekannte Nutzer erhalten ohne Zuordnung keinen Zugriff auf Veranstaltungsdaten. Die konfigurierte Adresse bekommt pro neuem wartendem Konto eine Nachricht über die bestehende Mail-Warteschlange.

Manuelle Stufen unten bleiben unabhängig von Microsoft bestehen. Rollen und Adminrechte unter Benutzer vergeben. Der Leitendenzugriff umfasst die bestehenden Stufenrechte einschließlich Löschen. Microsoft-Sitzungen gelten 15 Minuten, danach ist eine erneute Anmeldung nötig; Gruppenänderungen werden dabei neu übernommen.

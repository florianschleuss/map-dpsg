So wirken Rechte

Hier erscheinen die unterstützten Rechte, die MAP tatsächlich prüft. Weitere technische Django-Rechte werden nicht über diesen Editor verwaltet und beim Speichern nicht entfernt.

  1. Konto gesperrt: keinerlei Zugriff.
  2. Admin: fachlicher Vollzugriff. Manager: alle Veranstaltungen.
  3. Read-Only: keine Veranstaltungsänderungen, auch bei zusätzlichen Stufenrechten; Admin und Manager haben Vorrang.
  4. Leitendenstatus + eigene Stufen: automatischer vollständiger Zugriff auf diese Stufen.
  5. Rollen + Einzelrechte: zusätzliche Freigaben, beispielsweise für Jungpfadfinder.

Persönlich an einer Veranstaltung vergebene Bearbeitungsrechte erlauben Lesen, Bearbeiten und Löschen dieser Veranstaltung. Sie bestehen unabhängig von der Stufenzuordnung.

Read-Only betrifft Veranstaltungen und Formularvorlagen. Separat vergebene Verwaltungsrechte gelten zusätzlich.

Benutzer- und Rollenverwaltung erlauben das Vergeben weitreichender Rechte. Nur vertrauten Personen geben.
